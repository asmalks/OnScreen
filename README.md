# OnScreen Project

This project is a React web application built with Vite and Tailwind CSS.

## Getting Started

1. Set up environment variables:
   Copy `.env.example` to `.env.local` and fill in the required values (e.g. Supabase credentials).

2. Install dependencies:
   ```sh
   npm install
   ```

3. Start the development server:
   ```sh
   npm run dev
   ```

4. Build for production:
   ```sh
   npm run build
   ```

## Technologies Used

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Supabase (Auth + Database)
